# Project 5: Serverless Cloud Application Deployment

## Overview
This project demonstrates the deployment of a serverless application architecture using AWS Lambda and Amazon API Gateway.

## Key Features Implemented
- **Serverless Backend (AWS Lambda):** Created a Python-based serverless function to generate structured JSON responses on demand.
- **API Management (Amazon API Gateway):** Exposed the Lambda function as a public HTTP API endpoint.
- **Event-Driven Execution:** Configured seamless integration allowing web traffic to trigger backend function execution without managing server infrastructure.

## Verification
The application was verified by accessing the generated API endpoint URL in a web browser and confirming the returned JSON payload.
