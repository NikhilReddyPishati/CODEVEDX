#PROJECT 2: CLOUD STORAGE & BACKUP MANAGEMENT 

## Overview 
This Project demonstrates the implementation of a secure, scalable, and reliable cloud storage solution using Amazon Web Services (AWS) S3 for Bucket Creation

## Key
- **S3 Bucket Provisioning :** Created a dedicated S3 bucket ('codevedx-cloud-storage-nikhil') for structured object storage.
- **Automated Versioning:** Enabled Bucket Versioning to retain, recover, and restore previous versions of uploaded objects.
- **Data Protection:** Tested file overwrite safeguards by uploading multiple revisions of files under the same key ('tax.pdf') to verify unique version IDs.

## Verification
S3 Bucket Versioning Successfully generated unique Version IDs for each upload iteration, ensuring complete protection aganist accidental data loss or overwrite
