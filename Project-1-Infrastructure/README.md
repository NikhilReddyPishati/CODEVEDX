# Project 1 : Cloud Infrastructure Deployment

## Overview
This project demonstrated the design and deployment of scalable virtual infrastructure using Amazon Web Services (AWS) EC2.

## Key Features Implemented
- **Virtual Server provisioning:** Launched an AWS EC2 instance running Amazon Linux
- **Network Security Configuration:** Configured Security Groups to allow HTTP inbound traffic on port 80.
- **Automated Web Server Setup:** Used AWS User scripts to automatically install and enable Apache HTTP server ('httpd').

  ## Verification
  The Infrastructure was verified by accessing the server via its Public IPv4 address, configuring successful deployment and web server execution
